# Netra SDK Examples

This directory contains examples demonstrating how to integrate Netra SDK into your applications.

## 📁 Examples Overview

### 🔧 01_basic_setup/


- **`basic_initialization.py`** - Essential SDK setup with user, session, and tenant context
- **`configuration_options.py`** - Advanced configuration patterns for different environments



### 🎯 02_decorators/

- **`function_decorators.py`** - Master @workflow, @task, and @agent decorators
- **`class_decorators.py`** - Advanced class-level instrumentation patterns


### 🤖 05_llm_tracing/

- **`gemini.py`** - Google Gemini API integration and tracing
- **`cohere.py`** - Cohere API monitoring and tracing
